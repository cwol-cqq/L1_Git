L1_Git

Лабораторная работа по основам Git и GitHub.

Что сделано
- Основы: инициализация репозитория, коммиты, работа с файлами
- Ветки: создание `film` и `unlikedFilm`, слияние веток
- Конфликты: разрешение конфликта слияния в `film.txt`
- Pull Request: создан PR из ветки `film` в `main`

Содержимое

- `film.txt` — любимый фильм, сериал и мультфильм
- `unlikedFilm.txt` — нелюбимый фильм
- `img/` — картинка
